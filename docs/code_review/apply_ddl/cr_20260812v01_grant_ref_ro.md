   - 1.1. [minor] Lines 43-47: The precondition asserts that all three roles already hold database CONNECT "via the catalog grant scripts (grant_catalog_ci.sql / grant_catalog_ci_ro.sql / the mcp_ro_metadata setup)". Downgraded from `[major]`: the setup exists and is maintained, so this is a cross-reference defect in a comment, not a missing grant. 3. [completed] Make a partially-failed run visible - `code/apply_ddl/grant_ref_ro.sql`

        - Current: (no `ON_ERROR_STOP`; the file goes straight from the header comment to the `\if :{?schema}` default block on line 52)
        - Expected: `-- Abort on the first failed statement: a missing role or a not-yet-applied`<br>`-- ref migration must not leave a half-applied privilege model — above all a`<br>`-- missing default-privileges rule — behind a zero exit code.`<br>`\set ON_ERROR_STOP on`
        - Resolution: Implemented as specified — placed after the (now revised, per finding 1.1) Preconditions block and before the `\if :{?schema}` default, so it guards every statement including the closing `alter default privileges`.
